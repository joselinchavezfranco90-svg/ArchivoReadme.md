Description of Cineplus

PROJECT DESCRIPTION

The present project focuses on the development of a digital application designed to enhance the user experience within a movie theater through a modern, intuitive digital platform. The application is designed to allow users to check the movie listings, purchase tickets, buy concession products, and manage their tickets quickly and securely from any device.
It enables customers to fully manage their cinematic experience before, during, and after their visit to the theater.

The platform will include a login system, through which each user can create a personal account to access various features that will allow them to watch a movie.
Within the ticket office section, users will be able to view available movies, schedules, auditoriums, classifications, and select seats in real time, as well as complete ticket purchases easily.

The concession section will offer a full catalog of products such as popcorn, soft drinks, combos, and other items available at the theater. Users will be able to add items to their order along with their ticket purchase. The goal is for customers to pick up their products directly at the counter without having to wait.

The Ticket section will allow users to view and digitally store the tickets they have purchased.
Overall, the application aims to provide a comprehensive solution that modernizes the movie theater experience, offering convenience, speed, and efficiency for both users and the company. Its design focuses on usability, security, and accessibility, making it a complete tool for managing all theater services from one place.


Description of each window.

Window 1: The first window is for entering your username and password to access the following windows. If the username or password is incorrect, you will not be able to proceed.

Window 2: Calculate ticket sales, choose the movie and showtime, and select the number of children and adults who want tickets.

Window 3: This window is for concessions. It calculates the price of each item you order. You can specify the quantity of each item and view the available products and combos.

Window 4: This window displays the total cost of everything you have ordered in the other windows, such as the number of children's and adult tickets, sodas, popcorn, and combos.
